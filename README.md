# 上海夜景 Citywalk 手机图文路书

静态手机网页：两晚、一晚方案；每个主机位有实景参考、公共步道站位、朝向、拍摄顺序、苹果地图定位和逐段步行导航。

## 使用

直接打开 GitHub Pages。可用 `?plan=night1`、`?plan=night2`、`?plan=one` 选择方案。网站不收集位置、登录或行程数据。
